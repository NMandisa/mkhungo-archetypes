A set of custom Maven archetypes for creating projects with specific configurations and structures.

## Introduction

Mkhungo Archetypes provide a streamlined way to kickstart your projects with predefined templates, covering various scenarios such as multi-module projects, Spring Framework configurations, and more.

## Features

- **Spring Framework Integration**: Archetypes for projects using Spring Framework (not Spring Boot).
- **Hibernate ORM Setup**: Templates including Hibernate configurations.
- **Multi-Module Support**: Archetypes designed for multi-module Maven projects.
- **Customizable**: Easily adaptable to fit your specific project needs.

## Requirements

- **Java**: JDK 8 or higher
- **Maven**: 3.2 or higher
